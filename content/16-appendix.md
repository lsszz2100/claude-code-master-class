핵심 개념은 모두 다뤘습니다. 이 부록은 실무에서 자주 쓰이지만 앞 챕터에 자연스럽게 넣기 어려웠던 **알아 두면 좋은 기능·팁**을 모았습니다. 필요할 때 찾아보는 참조용으로 쓰세요.

## 세션 관리 — 대화를 브랜치처럼

Claude Code는 대화를 로컬에 저장합니다. 작업이 여러 번에 걸치면 매번 맥락을 다시 설명할 필요가 없습니다.

| 명령/플래그 | 하는 일 |
| --- | --- |
| `claude --continue` | 가장 최근 세션 이어가기 |
| `claude --resume` | 목록에서 골라 재개 |
| `/rename` | 세션에 이름 부여(예: `oauth-migration`) — 나중에 찾기 쉽게 |
| `/branch` | 다른 방향을 시도하려 대화를 분기 |
| `/fork` | 대화를 새 백그라운드 세션으로 복제 |

> 세션을 **브랜치처럼** 다루세요 — 워크스트림마다 이름 붙은 고유 컨텍스트를 갖게 하면 병렬 작업이 깔끔해집니다.

## Remote Control — 폰·브라우저로 **내 컴퓨터의 세션** 이어가기

책상에서 시작한 작업을 소파에서 폰으로, 또는 다른 컴퓨터의 브라우저로 이어받는 기능입니다(리서치 프리뷰). 핵심은 **세션이 계속 내 컴퓨터에서 돈다**는 것 — 폰·웹은 그 로컬 세션을 들여다보는 **창**일 뿐이라 파일시스템·MCP 서버·프로젝트 설정이 그대로 살아 있습니다.

```bash
claude remote-control          # 서버 모드 — 접속을 기다리며 세션 URL·QR 표시(스페이스바)
claude --remote-control        # 평소 인터랙티브 세션에 원격 접속만 켜기 (--rc)
/remote-control                # 세션 도중에 켜기 (VS Code 확장도 이 명령)
```

접속은 **세션 URL 열기 / QR 스캔 / claude.ai/code·모바일 앱의 세션 목록에서 이름으로 찾기** 셋 중 하나입니다. 터미널·브라우저·폰에서 **동시에** 메시지를 보낼 수 있고 서브에이전트·워크플로 진행 상황도 함께 동기화됩니다. 노트북이 잠들거나 네트워크가 끊겨도 돌아오면 자동 재연결하고, 그동안 밀린 알림을 몰아서 전달합니다.

| 구분 | Remote Control | Claude Code on the web (아래 절) |
| --- | --- | --- |
| 세션이 도는 곳 | **내 컴퓨터** | Anthropic이 관리하는 클라우드 VM |
| 로컬 파일·MCP·설정 | 그대로 사용 | 사용 불가(저장소를 클론) |
| 언제 쓰나 | 하던 로컬 작업을 **다른 기기에서 이어갈 때** | 로컬 준비 없이 **바로 시작**하거나, 안 받아 둔 저장소·병렬 작업 |

> **알아 둘 제약이 몇 가지 있습니다.**
> - **로컬 프로세스가 살아 있어야 합니다.** 터미널을 닫으면 세션은 오프라인이 됩니다. SSH로 붙은 원격 머신이라면 `tmux`·`screen` 안에서 띄우세요.
> - **API 키로는 안 되고** 구독(Pro·Max·Team·Enterprise) 로그인이 필요합니다. Bedrock·Google Cloud·Foundry에서는 쓸 수 없고, `ANTHROPIC_BASE_URL`이 `api.anthropic.com`이 아닌 곳을 가리켜도 꺼집니다.
> - **`DISABLE_TELEMETRY`·`DO_NOT_TRACK` 등을 켜 두면 조용히 못 씁니다** — 기능 플래그 평가가 막혀서입니다. 원인을 짚기 어려운 실패이니 기억해 두세요.
> - **일부 명령은 로컬 전용**입니다(`/plugin`·`/resume` 등). 폰·웹에서는 `/model sonnet`·`/effort high`처럼 **값을 인수로 붙여** 씁니다(피커가 없으므로).
> - 처음 쓰는 프로젝트라면 **그 디렉터리에서 `claude`를 한 번 실행해 신뢰 대화를 통과**시켜 두어야 합니다. 홈 디렉터리에서는 신뢰가 저장되지 않습니다.

**모바일 푸시 알림**은 Remote Control이 켜져 있을 때 동작합니다. 긴 작업이 끝나거나 결정이 필요할 때 Claude가 알아서 보내고, 프롬프트에 `테스트 끝나면 알려줘`처럼 요청할 수도 있습니다.

## 아티팩트 — 세션 산출물을 **볼 수 있는 페이지**로

터미널 텍스트가 매체로 안 맞는 결과물이 있습니다. 주석 단 diff, 대시보드, 나란히 놓고 고르는 선택지, 긴 작업 동안 채워지는 조사 타임라인 같은 것들 — **읽는 것보다 보는 게 빠른** 출력입니다. 아티팩트는 이런 결과물을 claude.ai의 **비공개 URL에 살아 있는 페이지**로 발행하고, 세션이 계속되면 **그 자리에서 갱신**됩니다. 링크를 공유하면 남도 볼 수 있습니다.

```text
이 PR을 diff에 주석을 달아 훑어 주는 아티팩트를 만들어 줘.
지난주 배포 실패를 서비스별 대시보드 아티팩트로 만들고, 조사하면서 계속 갱신해 줘.
```

Claude가 프로젝트에 HTML(또는 마크다운) 파일을 쓴 뒤 발행하며, **새 아티팩트를 처음 발행할 때는 허락을 구합니다**(이미 승인한 것을 다시 발행할 때는 안 묻습니다).

> **아티팩트는 앱이 아닙니다.** 백엔드 없는 **자체 완결 페이지 한 장**이라 폼 입력을 저장하거나 여러 경로를 서비스할 수 없고, 외부 요청도 막혀 있습니다(CSS·JS는 인라인, 이미지는 data URI, 예외는 Google Fonts와 MCP 커넥터 호출뿐). 백엔드가 필요한 사내 도구라면 직접 배포하세요.
> 또 **스타일 입힌 페이지는 같은 내용의 터미널 출력보다 출력 토큰을 많이 씁니다** — 특히 data URI로 박은 이미지가 그렇습니다.
> 쓰려면 **claude.ai 계정 로그인**(`/login`)이 필요합니다 — API 키·게이트웨이 토큰·클라우드 제공자 자격증명 세션은 발행할 수 없고, Bedrock·GCP·Foundry에서도 안 됩니다.

## Claude Code on the web · 클라우드 세션 · 예약 실행

- **웹/클라우드 세션**: Anthropic이 관리하는 **격리 VM**에서 세션을 돌릴 수 있습니다. 저장소를 클론해 원격에서 작업.
- **루틴(routines)·예약 작업**: 크론처럼 **예약된 클라우드 에이전트**를 돌려 "매일 밤 배포 점검" 같은 반복 작업을 자동화.
- **데스크톱 예약 작업**은 로컬 머신에서 돌아, `~/.claude/skills/`의 개인 스킬을 그대로 씁니다(클라우드 세션은 저장소에 커밋된 스킬만).

> **주의:** 클라우드/웹 세션은 로컬 `~/.claude/skills/` 를 읽지 않습니다. 개인 스킬을 원격에서 쓰려면 저장소 `.claude/skills/`에 커밋하거나 플러그인으로 배포하세요.

## 자동화·프로그래밍

- **헤드리스(비대화) 모드**: `claude -p "프롬프트"` — CI·pre-commit·스크립트에 통합. `--output-format json`으로 파싱, `--allowedTools`로 권한 제한([11장](#ch11)).

- **Claude API**: 직접 모델을 호출하는 저수준 경로. [모델 챕터](#ch3)의 모델 ID·effort가 그대로 적용됩니다.

## 번들 스킬 — 이미 들어 있는 강력한 도구들

`/`로 바로 쓰는 [번들 스킬](#ch4)들. 설치 없이 사용 가능합니다.

| 스킬 | 하는 일 |
| --- | --- |
| `/run` · `/verify` | 앱을 실제로 띄워 변경이 동작하는지 확인(테스트만이 아니라 실행으로) |
| `/code-review` | diff를 새 서브에이전트가 리뷰(`--fix`로 수정 적용) |
| `/security-review` | diff의 보안 취약점 점검 |
| `/batch` | 대규모 코드베이스 변경을 병렬로 오케스트레이션 |
| `/deep-research` | 웹 검색을 팬아웃해 리포트로 종합 |
| `/loop` | 프롬프트를 주기적으로 반복 실행([루프 엔지니어링](#ch13)) |
| `/doctor` | 셋업 점검·진단 |

> **`/code-review ultra`(= ultrareview)는 같은 리뷰의 "깊은 판"입니다**(리서치 프리뷰). 로컬 대신 **클라우드 샌드박스에서 리뷰어 에이전트 여러 대**를 띄워 브랜치나 PR을 훑고, **보고하는 지적마다 독립적으로 재현·검증**합니다 — 그래서 스타일 훈수가 아니라 진짜 버그 위주로 남습니다. 터미널은 그동안 비어 있습니다.
> 대신 **비싼 기능입니다.** 요금제 사용량이 아니라 **사용량 크레딧**에서 빠지고, Pro·Max에 **평생 3회 무료**(Team·Enterprise는 없음), 그 뒤로는 변경 크기에 따라 보통 **회당 $5~25**입니다. 실행 전 대화상자가 범위·남은 무료 횟수·예상 비용을 보여 주고, **중간에 멈춰도 무료 1회는 소모**됩니다. 여러분이 `/code-review ultra`를 직접 칠 때만 돌아가고 Claude가 알아서 시작하지 않습니다.

**저장소 전체를 훑는 보안 점검이 필요하면 Claude Security 플러그인**을 설치하세요([플러그인](#ch10)).

```text
/plugin install claude-security@claude-plugins-official
/claude-security          # 전체 스캔 · 변경분 스캔 · 패치 제안 메뉴
```

에이전트 팀이 아키텍처를 파악해 위협 모델을 세우고, 취약점을 찾은 뒤 **모든 지적을 독립적으로 재검토**해 리포트를 냅니다. 고른 지적은 패치로 바꿔 주되 **적용은 여러분이 검토해서** 합니다. 스캔은 로컬 세션에서 돌고 **요금제 사용량을 씁니다**.

> **보안 도구는 층으로 쌓입니다 — 하나로 다 하려 들지 마세요.**
>
> | 시점 | 도구 | 커버 범위 |
> | --- | --- | --- |
> | 코드를 쓰는 중 | 보안 가이던스 플러그인 | Claude가 쓰는 코드의 흔한 취약점을 그 세션에서 바로 |
> | 필요할 때 한 번 | `/security-review` | 현재 브랜치 1회 점검 |
> | 필요할 때 깊게 | **Claude Security 플러그인** | 저장소·diff 다중 에이전트 스캔 + 검증된 지적 + 패치 |
> | PR에서 | Code Review(Team·Enterprise) | 코드베이스 전체 맥락의 정확성·보안 리뷰 |

## 비용·성능 관리

- **`/usage`**로 API 사용량·비용 확인. 저비용이 필요하면 [모델·effort](#ch3)를 낮추세요.
- **프롬프트 캐싱**: 반복되는 큰 컨텍스트(예: `CLAUDE.md`)는 자동으로 캐시되어 최대 90% 절감. 세션 중 모델을 바꾸면 캐시가 무효화되니 잦은 전환은 피하세요.
- **릴리스 채널**: 네이티브 설치는 자동 업데이트. `/config`의 **Auto-update channel**에서 `latest`(최신) 또는 `stable`(약 1주 지연, 회귀 회피)을 고를 수 있습니다.
- **사용량 한도에 걸려도 세션은 이어집니다**(v2.1.234+): claude.ai 사용량 한도가 리셋되면 Claude Code가 **자동으로 이어서** 진행합니다. 원치 않으면 `/config`의 "Continue automatically at usage limit"에서 끄세요.
- **`claude doctor`**로 설치·설정 상태를 언제든 진단.

## 더 배우기 — Anthropic 공식 무료 강좌

Anthropic Academy의 **[Claude Code in Action](https://anthropic.skilljar.com/claude-code-in-action)**(무료)은 "단일 프롬프트를 넘어 **더 길고, 덜 감독하고, 팀 단위** 워크플로로" 나아가려는 개발자를 위한 실습 강좌입니다 — 플랜 모드·되감기, CLAUDE.md·스킬·권한, 예약 루틴·GitHub Actions, 무인 실행 검증까지. 이 강의를 마쳤다면 다음 단계로 좋습니다. 전체 리소스 지도는 [참고 자료 챕터](#ch17)를 보세요.

## 안전하게 쓰기 — 빠른 체크리스트

- 민감 작업은 **Manual(`default`)/plan 모드**로, 신뢰 작업은 **auto 모드**로([2장](#ch2)). Pro·Max·Team의 새 세션은 이제 **auto로 시작**하니, 민감한 저장소에서는 시작 모드를 직접 확인하세요.
- 반드시 막아야 하는 동작은 **CLAUDE.md 조언이 아니라 [훅](#ch9)**으로 강제.
- 무인 실행([루프](#ch13))에는 **검증(테스트·`/goal`·검증 서브에이전트)**을 반드시 게이트로.
- 외부 자산(서브에이전트·스킬·플러그인·MCP)은 **도입 전 내용 검토**.
- 되돌리기는 **`/rewind`·체크포인트**로, 단 Bash·외부 변경은 안 잡히니 **git이 최종 안전망**.

## 핵심 요약

- 세션은 **`--continue`·`--resume`·`/rename`·`/branch`**로 브랜치처럼 다룬다.
- **IDE·GitHub·Slack·데스크톱·웹·클라우드**까지 같은 엔진 — 헤드리스 `-p`와 **Agent SDK**로 자동화·프로그래밍.
- **Remote Control**은 내 컴퓨터의 세션을 폰·브라우저로 이어가는 것(로컬 실행), **웹/클라우드 세션**은 아예 클라우드에서 도는 것 — 로컬 파일·MCP가 필요하면 전자다.
- **번들 스킬**(`/run`·`/code-review`·`/security-review`·`/batch` 등)은 설치 없이 강력하다. 더 깊게 봐야 하면 **`/code-review ultra`**(클라우드 다중 에이전트, 사용량 크레딧)와 **Claude Security 플러그인**이 있다.
- **아티팩트**로 "읽는 것보다 보는 게 빠른" 산출물을 살아 있는 페이지로 공유한다 — 단 백엔드 없는 한 장짜리다.
- 비용은 **`/usage`·모델·effort·프롬프트 캐싱**으로, 안전은 **권한 모드·훅·검증·git**으로 관리한다.
